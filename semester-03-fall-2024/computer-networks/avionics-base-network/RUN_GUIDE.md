# Review Guide

This project is a Cisco Packet Tracer simulation for a fictional academic network.

## Requirements

- Cisco Packet Tracer, if you want to open the simulation file
- A document viewer for the report and presentation

## Open the Simulation

1. Install Cisco Packet Tracer.
2. Open `packet-tracer/avionics-base-network-simulation.pkt`.
3. Wait for links and routing to converge.
4. Review the HQ and facility site areas in the logical workspace.

## Review Without Packet Tracer

If Packet Tracer is not available, review:

- `README.md`
- `topology/logical-diagram.png`
- `configs/avionics-base-network-configs.md`
- `screenshots/verification-commands.md`
- `screenshots/`
- `docs/avionics-base-network-report.docx`
- `presentation/avionics-base-network-presentation.pptx`
