# Computer Networks - CS260L

## Course Overview

This folder contains public portfolio artifacts from the **Computer Networks** course completed in **Semester 3, Fall 2024** as part of the BS Cyber Security program at Air University, Islamabad.

The course focused on hands-on networking concepts using simulation and practical configuration tasks. The archived project demonstrates network design, VLAN segmentation, inter-site routing, network services, and verification using Cisco Packet Tracer.

## Key Skills Demonstrated

- Cisco Packet Tracer network simulation
- VLAN planning and segmentation
- Trunk links between distribution and access switches
- Inter-VLAN routing using Layer 3 switches
- Point-to-point WAN-style routed links
- OSPF dynamic routing
- Centralized DNS, Web, FTP, Mail, and Syslog services
- Network verification using CLI commands
- Service testing from end-user PCs
- Public-safe technical documentation for a GitHub portfolio

This course folder is relevant to cybersecurity because strong networking fundamentals are required for SOC analysis, penetration testing, network defense, incident response, and secure infrastructure design.
