# Review Guide

This is a report and presentation project, not a runnable software project.

## How to Review

1. Open `README.md` for the project overview.
2. Review `docs/hbl-contingency-framework-report.docx`.
3. Review `presentation/hbl-contingency-framework-presentation.pptx`.
4. Check `PROJECT_NOTES.md` for cleanup notes.

## Verification Scope

- There is no application build, runtime, or automated test suite for this project.
- Review is based on document completeness, consistency, academic scope, and public-safety wording.

## Safety Notes

- Treat the project as academic contingency-planning coursework.
- Do not add confidential banking data, internal policies, or real incident information.
