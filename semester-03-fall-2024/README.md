## Overview

This folder contains selected coursework and projects completed during **Semester 3 - Fall 2024** of the **BS Cyber Security** program at **Air University Islamabad**.

Semester 3 moved into stronger systems and infrastructure topics, including computer networks, data structures, computer organization and assembly language, information assurance, and management coursework. The public projects show network simulation, scheduler-style application logic, assembly/design documentation, contingency planning, and business intelligence reporting.

## Highlighted Projects

### Multi-Site Aviation Campus Network Simulation

The **Multi-Site Aviation Campus Network Simulation** is the main networking artifact from Semester 3. It demonstrates hierarchical network design, VLAN planning, routed links, network services, topology documentation, and CLI-style verification evidence in Cisco Packet Tracer.

**Key skills demonstrated:**

- Cisco Packet Tracer simulation
- VLAN segmentation
- Routing and service reachability
- Network documentation
- Public-safe infrastructure framing

### Competition Scheduler

The **Competition Scheduler** applies data structures to a tournament scheduling scenario. It preserves the original coursework and includes a reformed implementation with a C++ backend and C# WinForms frontend.

**Key skills demonstrated:**

- Data structures
- C++ backend logic
- C# WinForms frontend
- Original vs improved implementation tracking
- Sample data handling

### HBL Contingency Framework

The **HBL Contingency Framework** demonstrates information assurance planning through academic report and presentation artifacts.

**Key skills demonstrated:**

- Contingency planning
- Risk-aware documentation
- Information assurance concepts
- Academic reporting
