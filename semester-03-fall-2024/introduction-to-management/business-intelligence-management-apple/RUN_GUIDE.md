# Review Guide

This is a report and presentation project, not a runnable software project.

## How to Review

1. Open `README.md` for the project overview.
2. Review the report in `docs/`.
3. Review the presentation in `presentation/`.
4. Use `screenshots/` for quick visual evidence.
5. Check `PROJECT_NOTES.md` for cleanup notes.

## Safety Notes

- Keep the project framed as academic business-intelligence coursework.
- Do not add private company data or proprietary materials.
