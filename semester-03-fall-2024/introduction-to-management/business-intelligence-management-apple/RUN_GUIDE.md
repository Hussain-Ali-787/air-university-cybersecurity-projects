# Review Guide

This is a report and presentation project, not a runnable software project.

## How to Review

1. Open `README.md` for the project overview.
2. Review `docs/ManagementReport.pdf`.
3. Review `presentation/Introduction_to_Management_Project.pptx`.
4. Use `screenshots/` for quick visual evidence.
5. Check `PROJECT_NOTES.md` for cleanup notes.

## Verification Scope

- There is no software build, runtime, or automated test suite for this project.
- Review is based on document completeness, screenshot evidence, academic framing, and public-data safety.

## Safety Notes

- Keep the project framed as academic business-intelligence coursework.
- Do not add private company data or proprietary materials.
