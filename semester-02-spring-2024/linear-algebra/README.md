## Course Overview

This folder contains coursework and academic project material for the **Linear Algebra** course completed during **Semester 2, Spring 2024** as part of the **BS Cyber Security** program at Air University Islamabad.

The course introduced mathematical foundations used in computing, engineering, data analysis, artificial intelligence, cryptography, and cybersecurity. The included project demonstrates how systems of linear equations can be solved computationally using Gaussian elimination.

---

## Course Focus

The course focused on core Linear Algebra concepts and their practical application in computational problem solving.

Key areas covered include:

- Matrices and matrix operations
- Systems of linear equations
- Row operations
- Gaussian elimination
- Consistency of linear systems
- Unique, infinite, and no-solution cases
- Vector spaces and transformations
- Mathematical reasoning for computing problems
