# Run Guide

This project is a C++ Gaussian elimination solver.

## Requirements

- A C++17-compatible compiler
- PowerShell, Command Prompt, or a terminal

## Build

From this project folder:

```powershell
g++ src/gaussian_elimination_solver.cpp -o gaussian-elimination-solver
```

## Run

```powershell
.\gaussian-elimination-solver
```

Use the example inputs in `sample-data/` when prompted by the program.

## Sample Inputs

- `sample-data/unique-solution-input.txt`
- `sample-data/no-solution-input.txt`
- `sample-data/infinite-solutions-input.txt`
