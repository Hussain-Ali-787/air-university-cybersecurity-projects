## Overview

This folder contains academic coursework and project material from **Semester 2, Spring 2024** of the **BS Cyber Security** program at **Air University Islamabad**.

Semester 2 strengthened the foundation built in the first semester by introducing object-oriented programming, software engineering principles, digital logic design, linear algebra, applied physics, and supporting university studies. The public portfolio material in this folder focuses on selected technical projects that demonstrate programming, mathematical problem solving, software testing, circuit simulation, and digital logic implementation.

Some courses, such as **Quranic Studies** and **Sirat Ul Nabi**, are part of the university's recurring spiritual and ethical learning component. These courses usually include guest lectures, seminars, or reflective events each semester. They are acknowledged in the semester record, but they may not always have public technical artifacts suitable for a GitHub portfolio.

## Project Highlights

### Software Testing with Selenium

This project introduced software testing fundamentals using Selenium IDE. It covered functional testing, browser action recording, test execution, testing methodology, and introductory lab-level performance/stress testing concepts.

### Gaussian Elimination Solver

This project converted a Linear Algebra concept into a working C++ program. It demonstrates algorithmic thinking by solving systems of linear equations and identifying different solution types.

### Firewall Tutor in C#

This project connects object-oriented programming with a cybersecurity-inspired use case. It simulates firewall rule evaluation using sample packets and rules while demonstrating class-based design, service separation, GUI development, and CSV handling.

### 4-Way Traffic Signal Controller

This project demonstrates hardware-oriented thinking through a digital logic traffic controller. It includes Proteus simulation, a truth table, NE555 timing, counter-based sequencing, logic decoding, hardware photos, and demo media.
