## Overview

This folder contains selected coursework and projects completed during **Semester 2 - Spring 2024** of the **BS Cyber Security** program at **Air University Islamabad**.

Semester 2 expanded the first-semester foundation into object-oriented programming, software engineering, digital logic design, linear algebra, and supporting technical coursework. The public portfolio artifacts focus on programming, GUI development, algorithmic problem solving, software testing, circuit simulation, and digital logic implementation.

Some coursework from the semester may not have public project artifacts. This README acknowledges the semester scope while keeping the repository focused on work that has meaningful technical or documentary evidence.

## Highlighted Projects

### Firewall Tutor in C#

The **Firewall Tutor in C#** project connects object-oriented programming with a cybersecurity-inspired scenario. It demonstrates class design, service separation, CSV handling, GUI screens, sample rules, sample packets, and rule-based evaluation.

**Key skills demonstrated:**

- C# programming
- Windows Forms GUI development
- Object-oriented design
- CSV input/output handling
- Rule-based packet simulation
- Educational cybersecurity tooling

### Gaussian Elimination Solver

The **Gaussian Elimination Solver** translates a Linear Algebra concept into a working C++ program. It shows algorithmic problem solving through matrix operations and solution classification.

**Key skills demonstrated:**

- C++ programming
- Matrix operations
- Gaussian elimination
- Input-driven problem solving
- Handling multiple solution cases

### 4-Way Traffic Signal Controller

The **4-Way Traffic Signal Controller** demonstrates digital logic design through simulation and prototype evidence. It includes truth-table reasoning, timing, sequential logic, and visible hardware/simulation outputs.

**Key skills demonstrated:**

- Digital logic design
- Proteus simulation
- Truth table creation
- Sequential circuit concepts
- Hardware evidence documentation
