## Course Overview

This folder contains coursework and academic project material for the **Object Oriented Programming** course completed during **Semester 2, Spring 2024** as part of the **BS Cyber Security** program at Air University Islamabad.

The course introduced object-oriented programming concepts and their practical use in software development. The included project applies these concepts through a C# Windows Forms application based on an educational firewall simulation.

---

## Course Focus

The course focused on writing structured, reusable, and maintainable programs using object-oriented principles.

Key areas covered include:

- Classes and objects
- Encapsulation
- Abstraction
- Inheritance and polymorphism
- Constructors and methods
- Enumerations
- File handling
- GUI-based application development
- Basic software design
- Debugging and testing

## Learning Outcomes

This course helped build understanding of:

- How to design programs using classes and objects
- How to separate data models, logic, and user interface code
- How object-oriented design improves maintainability
- How GUI applications are structured in C#
- How file-based input and output can support applications
- How programming concepts can be applied to cybersecurity-inspired simulations
- How to document and present an academic software project
