## Course Overview

This folder contains coursework and academic project material for the **Introduction to Software Engineering** course completed during **Semester 2, Spring 2024** as part of the **BS Cyber Security** program at Air University Islamabad.

The course introduced core software engineering concepts including software development processes, requirements, design, testing, documentation, and project presentation.

---

## Course Focus

The course focused on understanding how software systems are planned, designed, tested, documented, and maintained.

Key areas covered include:

- Software engineering fundamentals
- Software development life cycle
- Requirements understanding
- Software testing concepts
- Functional and non-functional testing
- Test case design
- Software quality assurance
- Technical documentation
- Academic project presentation

## Learning Outcomes

This course helped build understanding of:

- How software engineering supports structured software development
- Why testing is important before software delivery
- How functional and non-functional testing differ
- How automated testing tools support software validation
- How test cases are designed and documented
- How project reports and presentations communicate technical work
- How software engineering concepts apply to real web-based systems

---

## Portfolio Relevance

Although this is an early-semester academic course, it adds value to the portfolio by showing:

- Understanding of software testing fundamentals
- Ability to document testing methodology
- Experience with Selenium IDE
- Awareness of testing tool selection
- Academic report writing and presentation skills
- Early exposure to software quality assurance concepts

This course is included to show the foundation of software engineering knowledge before moving into more advanced cybersecurity, systems, and security engineering projects.
