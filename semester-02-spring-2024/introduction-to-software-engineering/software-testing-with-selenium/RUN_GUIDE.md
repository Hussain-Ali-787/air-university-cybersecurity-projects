# Review Guide

This is a software testing report and presentation project. Selenium IDE evidence is included as documentation, but no runnable automated test suite is currently included.

## How to Review

1. Start with `README.md` for the testing overview.
2. Review the report in `docs/`.
3. Open the presentation in `presentation/`.
4. Review screenshots in `screenshots/`.
5. Check `PROJECT_NOTES.md` for cleanup and safety notes.

## Future Run Instructions

If Selenium test files are added later, document:

- Browser requirements
- Selenium IDE or WebDriver version
- Test target setup
- Safe sample credentials, if any
- Test execution steps

## Safety Notes

- Do not add private target websites, accounts, credentials, browser profiles, or session data.
- Keep testing examples authorized and academic.
