# Review Guide

This project is a Digital Logic Design simulation and hardware evidence project.

## Requirements

- Proteus, if you want to open the simulation file
- A spreadsheet viewer, if you want to inspect the truth table
- A media player, if you want to view the demo video

## How to Review

1. Start with `README.md`.
2. Read `REPORT.md` for the project explanation.
3. Open `design/4way-signal-truth-table.xlsx` for the truth table.
4. Open `proteus/FourWayTrafficSignal_Recreated.pdsprj` in Proteus if available.
5. Review `proteus/Proteus-Reconstruction-Guide.md` for simulation reconstruction notes.
6. Check `screenshots/` and `media/` for visual evidence.

## Safety Notes

This is an academic prototype and simulation. It is not a real traffic-control deployment.
