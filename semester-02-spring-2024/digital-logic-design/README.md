## Course Overview

This folder contains coursework and academic project material for the **Digital Logic Design** course completed during **Semester 2, Spring 2024** as part of the **BS Cyber Security** program at Air University Islamabad.

The course introduced the foundations of digital systems, combinational logic, sequential circuits, counters, timing circuits, and hardware simulation. The included project demonstrates these concepts through a 4-way traffic signal controller implemented using Proteus and hardware prototype evidence.

---

## Course Focus

The course focused on digital circuit design and the logic principles used in computer hardware and embedded systems.

Key areas covered include:

- Number systems and binary representation
- Logic gates
- Boolean algebra
- Truth tables
- Combinational logic circuits
- Sequential logic circuits
- Flip-flops and counters
- Timing circuits
- Circuit simulation
- Hardware implementation and testing

## Learning Outcomes

This course helped build understanding of:

- How digital systems represent and process binary states
- How logic gates are used to implement decision logic
- How truth tables define circuit behavior
- How counters can control sequential systems
- How timing circuits generate clock pulses
- How Proteus can be used for circuit simulation
- How hardware prototypes validate digital design concepts
- How digital logic supports computer architecture and embedded systems
