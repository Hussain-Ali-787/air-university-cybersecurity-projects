# Demo Notes

## Safe Demo Setup

Use only dummy hashes and lab-created passwords.

Recommended demo flow:

1. Open Kali Linux.
2. Create a dummy password.
3. Generate an MD5 hash for that dummy password.
4. Save the hash in a local text file.
5. Create a small custom wordlist using CUPP.
6. Run John the Ripper against the dummy hash.
7. Show the cracked password.
8. Explain why weak passwords are risky.
9. Explain mitigations.

## Important Safety Rule

Never use real credentials, leaked hashes, university accounts, or third-party systems for demonstration.
