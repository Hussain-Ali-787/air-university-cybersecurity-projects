# Review Guide

This is an introductory cybersecurity lab and presentation artifact. It is documented for defensive learning and should not be treated as an offensive playbook.

## How to Review

1. Start with `README.md` for the project overview and ethics framing.
2. Open the slide deck in `presentation/`.
3. Review selected screenshots in `screenshots/`.
4. Check `PROJECT_NOTES.md` for safety and cleanup notes.

## Safety Notes

- Use only authorized lab examples.
- Do not add real password hashes, cracked credentials, private wordlists, or unauthorized target data.
- Keep the focus on password security awareness and defensive lessons.
