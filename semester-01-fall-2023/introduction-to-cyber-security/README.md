## Overview

This folder contains coursework completed for **Introduction to Cyber Security** during Semester 1 of the BS Cyber Security program at Air University Islamabad.

The course introduced foundational cybersecurity concepts, including cyber threats, password security, ethical hacking basics, security tools, cyber awareness, and responsible use of security technologies. The included project demonstrates an introductory password security lab using John the Ripper in an authorized academic environment.

## Portfolio Relevance

This course is important in the portfolio because it shows the beginning of practical cybersecurity learning. The hash cracking project introduces password security concepts and demonstrates how security tools can be used in a controlled lab to understand real-world risks.

Although this is an introductory project, it is directly related to cybersecurity and supports later work in offensive security, ethical hacking, malware analysis, penetration testing, and security research.

## Safety and Ethics

All cybersecurity-related material in this folder is for academic, defensive, and authorized learning only.

The included hash cracking project uses lab-based examples and is documented to explain password security concepts. It is not intended for unauthorized access, credential theft, or misuse of security tools.

## Academic Notice

This coursework was completed for academic learning and portfolio documentation. The project is maintained as part of a cybersecurity academic portfolio to show early practical exposure to cybersecurity tools and concepts.
