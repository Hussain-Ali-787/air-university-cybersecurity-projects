## Overview

This folder contains coursework completed for **Discrete Structures** during Semester 1 of the BS Cyber Security program at Air University Islamabad.

The course introduced mathematical foundations used in computer science and cybersecurity, including sets, logic, relations, functions, graph-based representation, and structured reasoning. The included project focuses on **Relations and Their Properties**, a core topic used in databases, access-control models, graph theory, and formal computing concepts.
