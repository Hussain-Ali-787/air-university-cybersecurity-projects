# Review Guide

This is a presentation-based Discrete Structures project. It is not a runnable software project.

## How to Review

1. Start with `README.md` for the concept summary.
2. Open the slide deck in `presentation/`.
3. Review selected previews in `screenshots/`.
4. Check `PROJECT_NOTES.md` for cleanup notes.

## Notes

The project should remain positioned as mathematics coursework, with any computing or database examples treated as conceptual illustrations.
