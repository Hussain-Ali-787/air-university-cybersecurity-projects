# Review Guide

This is a presentation-based academic project. It is not a runnable software project.

## How to Review

1. Start with `README.md` for the topic overview.
2. Open the slide deck in `presentation/`.
3. Review selected slide previews in `screenshots/`.
4. Check `PROJECT_NOTES.md` for cleanup and safety notes.

## Safety Notes

- Keep the project educational and defensive.
- Do not add confidential telecom data, internal diagrams, credentials, or private incident details.
