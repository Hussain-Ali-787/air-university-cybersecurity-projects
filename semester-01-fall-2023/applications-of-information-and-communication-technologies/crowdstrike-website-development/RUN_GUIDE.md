# Review Guide

This is a presentation and website-concept coursework artifact. The original website was created with Wix, so there is no runnable source code in this repository.

## How to Review

1. Start with `README.md` for the project overview.
2. Open the slide deck in `presentation/`.
3. Review `screenshots/` for website and presentation evidence.
4. Check `PROJECT_NOTES.md` for cleanup and safety notes.

## Safety Notes

- Do not add private Wix account dashboards or editor screenshots.
- Keep this project framed as an academic website-development exercise.
- Do not add real credentials, private analytics, or account information.
