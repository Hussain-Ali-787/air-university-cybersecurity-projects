# Review Guide

This is a Functional English presentation artifact focused on cybersecurity awareness. It is not a runnable software project.

## How to Review

1. Start with `README.md` for the communication and topic overview.
2. Open the slide deck in `presentation/`.
3. Review selected slide previews in `screenshots/`.
4. Check `PROJECT_NOTES.md` for cleanup and safety notes.

## Safety Notes

- Keep claims appropriate for academic presentation work.
- Do not add private student, classroom, or institutional information.
