## Overview

This folder contains coursework completed for **Functional English** during Semester 1 of the BS Cyber Security program at Air University Islamabad.

The course focused on improving communication, presentation, academic writing, and public speaking skills. The included project connects English communication skills with a cybersecurity topic by presenting the current state of cybersecurity in Pakistan.
