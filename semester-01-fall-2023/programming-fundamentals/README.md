## Overview

This folder contains coursework completed for **Programming Fundamentals** during Semester 1 of the BS Cyber Security program at Air University Islamabad.

The course introduced core programming concepts such as variables, control structures, functions, file handling, arrays, modular programming, and problem-solving using C++. The included project applies these concepts to a cybersecurity-inspired firewall rule engine.
