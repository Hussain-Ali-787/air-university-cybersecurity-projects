## Overview

This folder contains selected coursework and projects completed during **Semester 1 — Fall 2023** of the **BS Cyber Security** program at **Air University Islamabad**.

Semester 1 introduced the academic and technical foundations of the degree, including ICT concepts, programming fundamentals, discrete mathematics, English communication, introductory cybersecurity, and Islamic studies/ethics. The uploaded projects show early-stage academic work, basic technical development, cybersecurity awareness, presentation skills, communication practice, and the beginning of practical security learning.

The projects in this semester are preserved as part of an academic portfolio to show progression from foundational concepts toward more advanced cybersecurity and software development work.

Some coursework, such as **Islamic Studies and Ethics**, was based on debate and class participation rather than a technical project artifact. It is acknowledged in this semester record, but it is not forced into a separate GitHub project folder because there is no meaningful public technical evidence to archive.

## Highlighted Projects

### Firewall Rule Engine in C++

The **Firewall Rule Engine in C++** is one of the strongest Semester 1 projects because it combines programming fundamentals with a cybersecurity-inspired problem. It demonstrates file handling, modular C++ code, rule parsing, default-deny behavior, and basic packet-filtering logic.

**Key skills demonstrated:**

- C++ programming
- File handling
- Modular code structure
- Rule-based decision making
- Basic firewall logic
- Input validation
- Cybersecurity-themed software development

### Hash Cracking with John the Ripper

The **Hash Cracking with John the Ripper** project is the main practical cybersecurity project from Semester 1. It introduces password security, hashing, wordlists, Linux-based tools, and defensive lessons around password strength and secure authentication.

**Key skills demonstrated:**

- Linux tool usage
- Password security concepts
- Hash cracking in an authorized lab
- Cybersecurity ethics
- Tool demonstration
- Security awareness and mitigation

### Debate and Class Participation in Islamic Studies and Ethics

The **Islamic Studies and Ethics** component contributed to ethical understanding, discussion skills, and classroom participation. Since the activity was debate/class participation based, it is documented in the semester README rather than archived as a separate technical project.

**Key skills demonstrated:**

- Ethical reflection
- Debate participation
- Classroom discussion
- Communication skills
- Respectful argumentation
- Academic engagement

## Safety and Ethics

All cybersecurity-related material in this semester is for academic, defensive, and authorized learning only.

The hash cracking project uses lab-based examples and is documented to explain password security concepts, not to support unauthorized access. The firewall project is a simplified simulation and does not inspect, capture, modify, or block real network traffic.

The Islamic Studies and Ethics activity is included as a non-technical academic participation component and is not represented as a cybersecurity or software project.
