## Organization Standard

Final year project material should follow the repository-wide standards:

- Keep source code, documentation, screenshots, datasets, and reports separated.
- Do not commit real user data, private platform exports, credentials, or API keys.
- Use synthetic or sanitized examples for public demonstrations.
- Add a `RUN_GUIDE.md` when a runnable prototype exists.

See [../PROJECT_STANDARDS.md](../PROJECT_STANDARDS.md) for the full standard.
