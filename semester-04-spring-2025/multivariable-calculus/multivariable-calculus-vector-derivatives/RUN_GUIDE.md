# Review Guide

This is a presentation-based Multivariable Calculus project. It is not a runnable software project.

## How to Review

1. Start with `README.md` for the topic overview.
2. Open the slide deck in `presentation/`.
3. Review selected slide previews in `screenshots/`.
4. Check `PROJECT_NOTES.md` for cleanup notes.

## Notes

The project connects vector derivatives to cybersecurity concepts at an academic presentation level. It does not include code, datasets, or executable tooling.
