# Review Guide

This is a network security analysis and report project, not a runnable attack toolkit.

## How to Review

1. Start with `README.md`.
2. Review the final report in `docs/`.
3. Review references in `references/`.
4. Use `screenshots/` for visual evidence and report previews.
5. Check `PROJECT_NOTES.md` for cleanup notes.

## Safety Notes

- Keep the project framed as defensive, academic network security analysis.
- Do not add real packet captures, unauthorized target details, attack scripts, or credentials.
- Any lab evidence should be sanitized before publishing.
