## Overview

This folder contains selected coursework and projects completed during **Semester 4 - Spring 2025** of the **BS Cyber Security** program at **Air University Islamabad**.

Semester 4 contains more advanced cybersecurity and systems coursework, including malware analysis, network security, operating systems, secure software development, and multivariable calculus. The public artifacts show defensive malware analysis documentation, network security analysis, secure web application design, kernel scheduler experimentation, and technical presentation work.

## Highlighted Projects

### Secure Student Management System

The **Secure Student Management System** is a runnable Flask application showing practical secure software development improvements in a small academic CRUD system.

**Key skills demonstrated:**

- Flask application structure
- Secure password hashing
- CSRF protection
- Session security settings
- Docker/local run documentation
- Secure coding cleanup

### NetSupport RAT Analysis

The **NetSupport RAT Analysis** project documents safe malware analysis work while intentionally excluding the live sample.

**Key skills demonstrated:**

- Static and dynamic analysis documentation
- IOC extraction
- YARA rule writing
- Safe malware repository hygiene
- Defensive analysis reporting

### Round-Robin Kernel Scheduler Experiment

The **Round-Robin Kernel Scheduler Experiment** studies scheduler behavior through source comparison, benchmark scripts, collected results, and report artifacts.

**Key skills demonstrated:**

- Operating systems experimentation
- Linux scheduler source review
- Benchmark result interpretation
- Report generation
- Lab safety documentation

## Safety and Ethics

All cybersecurity work in this semester must remain academic, lab-based, defensive, and authorized. Do not add live malware, unauthorized attack code, real packet captures, private forensic material, credentials, sensitive infrastructure data, or unsafe payloads.
